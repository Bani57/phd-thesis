# Scalable Methods for Knowledge Graph Reasoning and Generation

This repository contains the source file of my PhD thesis, entitled **Scalable Methods for Knowledge Graph Reasoning and
Generation**, and supervised by Volkan Cevher. This was completed at EPFL between 2021 and 2025. The published version
of my thesis is available
on [infoscience](https://doi.org/10.5075/epfl-thesis-11478).
